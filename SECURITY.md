# Security Policy

## Supported Versions

| Version | Supported          |
| ------- | ------------------ |
| 1.0.x   | :white_check_mark: |

## Reporting a Vulnerability

If you discover a security vulnerability within `Invoke-SysRepair`, please send an email to `ghoste@atomicmail.io` or open a private advisory on GitHub. All security vulnerabilities will be promptly addressed.
